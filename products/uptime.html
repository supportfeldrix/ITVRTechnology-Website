Uptime Monitoring v1.0 · Windows

Windows 10/11 · no install needed · runs in the system tray · ~24 MB

Download for Windows
  1. Unzip the download and put UptimeMonitor.exe in a folder of its own, e.g. C:\UptimeMonitor. No Python or install needed.
  2. Double-click UptimeMonitor.exe. Your browser opens automatically at http://localhost:5000.
  3. On first run, create your admin account right in the browser — choose a username and password.
  4. You're in. Go to Settings → About → Branding to set your own name and logo.
Your data (database + keys) is saved next to the .exe — keep it in a writable folder and back those files up.
⬇ Download RPM (RHEL / Rocky / Alma / Fedora)
For RPM-based Linux · installs as a systemd service · ~ small download (sets up dependencies on install)
  1. Install it (sets up a service account, Python environment and a systemd service automatically): 
    sudo dnf install ./uptime-monitor-1.0.0-1.fc45.x86_64.rpm
    Needs internet to fetch Python dependencies on install. Air-gapped? See offline notes below.
  2. It starts automatically. Open the dashboard in a browser: 
    http://<your-server>:5000/
  3. On first run, create your admin account right in the browser — then set your branding and add monitors.
  4. Manage the service any time: 
    systemctl status uptime-monitor
journalctl -u uptime-monitor -f
HTTPS / auto-start on boot are built in (systemd). For HTTPS put nginx in front using the included LINUX_SETUP/nginx-uptime-monitor.conf. Offline servers: see the OFFLINE section in the package README. Debian/Ubuntu (.deb) is coming soon — let us know if you need it.

Keep your secret.key and encryption.key safe and backed up — the latter decrypts stored database credentials.
