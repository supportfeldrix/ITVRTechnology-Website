Uptime Monitoring v1.0 · Windows

Windows 10/11 · no install needed · runs in the system tray · ~24 MB

Download
  1. Unzip the download and put UptimeMonitor.exe in a folder of its own, e.g. C:\UptimeMonitor. No Python or install needed.
  2. Double-click UptimeMonitor.exe. Your browser opens automatically at http://localhost:5000.
  3. On first run, create your admin account right in the browser — choose a username and password.
  4. You're in. Go to Settings → About → Branding to set your own name and logo.
Your data (database + keys) is saved next to the .exe — keep it in a writable folder and back those files up.
