Gateway · Available now

Route, secure and watch your APIs from one place.

A lightweight, self-hosted API gateway with a built-in management dashboard. Define routes and upstreams, add authentication and rate limiting, and see live traffic, latency and container health — all running on your own Linux server with a single command.

What's in the box

A gateway and the dashboard to run it — nothing else to assemble.

🧭

Dynamic routing

Match requests by host, path and method. Add or change routes from the dashboard and they take effect immediately — no restart.

⚖️

Upstreams & load balancing

Send traffic to one or many backend nodes with round-robin or weighted balancing.

🔐

JWT authentication

Protect any route by requiring a valid bearer token. Invalid or missing tokens are rejected before they reach your service.

⏱️

Rate limiting & CORS

Cap requests per client with a configurable window, and handle cross-origin requests per route.

📈

Live monitoring

Traffic trend, status-code breakdown, per-route totals and latency over time, with a per-minute traffic report.

📜

Log viewer

Browse recent requests with route, status and path filters. History is kept on disk and survives restarts (7 days by default).

🐧

Container health

See your gateway's containers — state, CPU and memory — right in the dashboard, without logging in to the server.

💾

Backup & restore

Export all routes, upstreams and consumers to a file and import them again — merge or full replace.

👥

Roles & dark mode

Admin and viewer roles keep changes in the right hands, in a clean light or dark interface.

Up and running in four steps

Pre-built containers — nothing to compile, no internet needed after the download.

1

Download & extract

Grab the package and unpack it with tar xzf on your Linux server.

2

Run the installer

Run ./install.sh. It loads the images and starts the gateway and dashboard.

3

Sign in

Open the dashboard on port 8081, sign in as admin and change the password straight away.

4

Add your first route

Create an upstream, point a route at it, and send traffic through the gateway on port 8080.

Gateway v1.0.0 · Linux (Podman)

Fedora / RHEL / Rocky / Alma · pre-built containers · works offline · ~76 MB

⬇ Download for Linux

Requirements

  1. A Linux server or workstation with Podman (installed by default on Fedora; otherwise sudo dnf install -y podman).
  2. Ports 8080 (gateway), 8081 (dashboard) and 9180 (admin API) free. All three can be changed in the config file.

Install

  1. Extract the package: 
    tar xzf itvr-gateway-1.0.0.tar.gz
cd itvr-gateway-1.0.0
  2. (Recommended) Set your own admin password and secret before the first start: 
    cp .env.example .env
nano .env
  3. Install and start: 
    ./install.sh
  4. Open the dashboard and sign in: 
    http://<your-server>:8081
    Default login is admin / admin123 unless you changed it in .env. Change it on first sign-in.
Your routes, upstreams, users and request logs are stored in a Podman volume, so they survive restarts and upgrades. To stop it: ./uninstall.sh (keeps your data) or ./uninstall.sh --purge (removes everything). The full guide is included in the package as INSTALL.md.

This release is for Linux with Podman. Windows and macOS are not supported yet. Need help or another platform? Get in touch.
